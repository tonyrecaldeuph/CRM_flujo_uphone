# Architecture Decision Records (ADR)

Registro de decisiones arquitectónicas significativas. Cada ADR explica el **porqué** (intención)
detrás de una elección, no el cómo (eso lo explica el código). Formato: Estado · Contexto ·
Decisión · Consecuencias · Alternativas.

> Regla del proyecto: si una decisión toca la arquitectura, se crea o actualiza un ADR aquí.
